
# 💰 Personal Expense Tracker

A Python-based interactive expense tracking dashboard built using Streamlit, Pandas, and Plotly.

## 📌 Project Overview

Personal Expense Tracker helps users record daily expenses, monitor monthly budgets, and analyze spending patterns through an interactive dashboard.

## 🚀 Features

- Add daily expenses
- View monthly spending summary
- Track total transactions
- Calculate daily average spending
- Interactive category-wise donut chart
- View recent expenses
- Filter expense history by category
- Delete expenses with confirmation
- Set and save monthly budgets
- Monitor remaining budget
- Visualize budget usage with a progress bar
- Budget exceeded warning
- Professional light-themed dashboard

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Plotly
- CSV for expense storage

## 📂 Project Structure

Personal_Expense_Tracker/
- app.py
- requirements.txt
- README.md
- .streamlit/
  - config.toml

The application creates expenses.csv and budget.txt locally.

## ⚙️ Installation

1. Clone the repository.

2. Install dependencies:

```bash
python -m pip install -r requirements.txt
```

3. Run the application:

```bash
python -m streamlit run app.py
```

4. Open the local URL displayed in the terminal.
